# Collaboration browser evidence

Generated by `npm run e2e:collaboration` using an isolated KetSuite database and
Chrome in headless mode at a 1440 × 1100 viewport.

- `product-chatter.png`: Product detail with hydrated Chatter and Activity islands.
- `transfer-chatter.png`: Stock transfer detail with Chatter, an internal note and a planned activity.
- `my-activities.png`: actor-owned due list with completion, reschedule and cancel actions.
- `calendar-agenda.png`: hydrated 30-day agenda and event composer.
- `calendar-week.png`: seven-day calendar grid.
- `calendar-month.png`: 42-cell month grid including adjacent-month days.
- `notification-inbox.png`: authenticated unread notification inbox.
- `transactional-outbox.png`: immutable delivery snapshots with sent and terminal-failure states.
- `inbound-email-log.png`: processed reply/alias events plus failed and ignored routing diagnostics.
- `browser-e2e.json`: browser navigation/interactive timings and the assertions run.

The command logs in through the real session route, waits for each island to reach
`ready`, posts through both bridge APIs, schedules and completes an Activity from
the rendered island, proves an HTML payload remains text, checks outbound and inbound delivery logs,
and captures the full-page screenshots.
