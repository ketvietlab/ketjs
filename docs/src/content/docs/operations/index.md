---
title: Operations and migration
description: Runbooks for deploying, migrating, observing, and safely operating KetJS applications.
---

This cluster contains operational material that developers need after implementation:

- deployment and environment configuration;
- database and module migrations;
- queue workers, retries, and failure recovery;
- storage, S3-compatible services, streams, and transport integration;
- release cutover and rollback runbooks;
- production diagnostics and performance checks.

Implementation guides explain how to build a capability. Operational runbooks explain how to keep
that capability safe and observable in production.
