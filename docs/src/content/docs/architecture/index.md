This cluster explains why KetJS behaves the way it does. It is the home for:

- architectural decisions and open design questions;
- the unified manifest and composition model;
- application lifecycle and module discovery;
- security, isolation, and dependency boundaries;
- benchmarks and performance methodology.

Read these documents when extending a core contract, reviewing a trade-off, or validating that a
change preserves an existing invariant.
