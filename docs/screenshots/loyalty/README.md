# Loyalty screen evidence

Fixture: `tools/loyalty-visual.ts`, isolated SQLite, signed-in company context `KING`.

Every affected screen is captured as Vietnamese desktop at `1440×900` and English mobile at
`390×844`. The three Sale order states provide before/after evidence for code application and reward
redemption; the POS reward state proves the POS adapter renders the same contract.
