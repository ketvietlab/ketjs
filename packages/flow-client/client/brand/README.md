# Flow brand assets

Source supplied by the user: `~/dev/ketsuite-logo/logo-flow-light.png` (1846 × 444) and `logo-flow-dark.png` (1650 × 410).

Resized proportionally with macOS `sips --resampleWidth WIDTH SOURCE --out OUTPUT` at widths 160, 320 and 480 for the 160 × 40px FlowLogo slot. Transparency and original artwork/colors are preserved; no crop or recoloring. Light/dark images intentionally use their respective original aspect ratios with contain sizing.

These are private product assets. `brand.css` feeds them to the public kit's `FlowLogo` slot through `--flow-logo-light` / `--flow-logo-dark`; the kit itself ships no artwork.
