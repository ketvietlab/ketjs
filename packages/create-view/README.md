# @ketvietlab/create-view

Project generator for static ketjs-view sites.

Run `npm create @ketvietlab/view@latest my-site`, install dependencies, and start the development server with `npm run dev`.

The current source generator emits TSX pages and islands with the automatic ketjs-view JSX runtime.
This starter update is pending the next release; published 0.1.41 output can still use its older
syntax. Build and run the generator from this checkout to try the new starter.
